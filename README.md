#  نُقلة | NaKla
### من سيرة ذاتية عادية.. إلى فرصة حقيقية!

منصة متكاملة مدعومة بالذكاء الاصطناعي لتطوير وتحسين السير الذاتية، ترجمتها احترافياً، مواءمتها مع متطلبات الوظائف، والتحضير الكامل للمقابلات الشخصية لضمان تفوقك في نظام فحص السير الذاتية (ATS).

##  المميزات الرئيسية للمنصة

* **تقييم ATS شامل وواقعي:** حساب دقيق لمقاييس التوافق مع توصيات تفصيلية للهيكل، أرقام الإنجازات، والكلمات المفتاحية.
* **مواءمة السيرة الذاتية (CV Tailoring):** تخصيص نقاط الخبرة والمشاريع تلقائياً لتعكس متطلبات الوظيفة المطلوبة.
* **تحليل الفجوة المهنية (Skills Gap Analysis):** تحديد المهارات والتقنيات التي تنقصك مقارنة بالوظيفة المستهدفة واقتراح مصادر تعليمية مجانية لتعلمها.
* **منشئ خطابات التغطية (Cover Letter Generator):** صياغة خطابات تغطية مقنعة واحترافية متطابقة مع الفرصة المستهدفة.
* **الترجمة الذكية:** ترجمة فورية للسير الذاتية إلى الإنجليزية أو العربية مع الحفاظ على التنسيق والرموز.
* **تصميم عصري متطور:** يدعم الوضع المظلم والمضيء بالكامل، مع واجهة مستخدم سريعة الاستجابة (Responsive).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **الواجهة الأمامية (Frontend):** React 19, TypeScript, Tailwind CSS v4, Motion (Framer Motion).
* **الخلفية (Backend):** Node.js, Express.
* **محرك الذكاء الاصطناعي:** Google Gemini API.
* **بناء وتصدير الملفات:** html2canvas, jsPDF (لتنزيل السير الذاتية المعدلة كملف PDF عالي الجودة).
* **إدارة الاتصالات:** Nodemailer (SMTP لإرسال OTP)، Google OAuth 2.0.

## 📁 هيكلية المشروع (Project Architecture)

يتبع المشروع هيكلاً برمجياً نموذجياً واحترافياً (Modular Architecture):

```
nakla/
├── server/                      # كود الخلفية (Backend Express)
│   ├── index.ts                 # نقطة الدخول للسيرفر
│   ├── config.ts                # الإعدادات والمتغيرات البيئية
│   ├── middleware.ts            # البرمجيات الوسيطة وإعدادات الكاش والضغط
│   ├── static.ts               # تهيئة الملفات الثابتة للإنتاج
│   ├── lib/                     # مكتبات الذكاء الاصطناعي والذاكرة المؤقتة
│   └── routes/                  # مسارات وواجهات الـ API المنفصلة
│
└── src/                         # كود الواجهة الأمامية (Frontend React)
    ├── main.tsx                 # نقطة الانطلاق
    ├── app/                     # المكون الرئيسي وملف التنسيق العام
    ├── features/                # ميزات التطبيق (كل ميزة في مجلد مستقل)
    └── shared/                  # المكونات والمكتبات المشتركة
```

## التشغيل والتثبيت المحلي

### 1. المتطلبات الأساسية
* تثبيت إصدار Node.js 18 أو أحدث.
* الحصول على مفتاح Gemini API.

### 2. إعداد المتغيرات البيئية
أنشئ ملف `.env` في المجلد الرئيسي للمشروع وأضف البيانات التالية:
```env
GEMINI_API_KEY=your_gemini_api_key

# اختياري لتسجيل الدخول بجوجل
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# اختياري لإرسال رموز التحقق عبر البريد
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your_email@gmail.com
SMTP_PASS=your_app_password
```

### 3. التثبيت والتشغيل
```bash
# تثبيت الحزم التبعية
npm install

# تشغيل خادم التطوير (Frontend + Backend)
npm run dev
```
افتح الرابط `http://localhost:3000` in your browser.
